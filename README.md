Welcome to my game development journey! This repository contains 2 amazing Python games built with Pygame.

### 🚀 Live Games

#### 1. ❌⭕ Tic-Tac-Toe AI (Unbeatable)
My first AI game! You can never win against it.
- **Concept:** Minimax Algorithm
- **File:** `game.py`
- **How to run:** `python game.py`

#### 2. 🐦 Flappy Bird PRO
Full featured Flappy Bird clone with score and restart.
- **Features:** Score System, Collision Detection, Game Over & Restart (Press R)
- **File:** `flappy.py`
- **How to run:** `python flappy.py`

### 🛠️ Tech Stack
- Python 3
- Pygame Library
- AI Logic (Minimax)

### 💻 How to Run Any Game
1. Install Pygame: `pip install pygame`
2. Run: `python game.py` or `python flappy.py`
